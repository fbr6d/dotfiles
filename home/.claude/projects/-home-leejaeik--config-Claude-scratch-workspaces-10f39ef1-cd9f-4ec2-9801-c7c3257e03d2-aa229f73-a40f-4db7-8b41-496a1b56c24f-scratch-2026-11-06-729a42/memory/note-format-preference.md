정리노트 PDF는 "베껴쓰기좋게, 디자인은 너무 안예뻐도돼"라고 했다. 색·장식보다 흑백·테두리·표 위주의 필사하기 쉬운 형식으로 만든다.
국어 안키 덱에서는 "독서 단어가 너무 쉬워. 없애. 법 관련 단어를 대폭 추가해"라고 했다.

**Why:** 손으로 베껴 쓰며 외우는 용도라 장식은 방해가 되고, 기본 한자어는 이미 알고 있어 학습 가치가 낮다.

**How to apply:** 학습 PDF는 흑백 위주에 필사 체크칸을 둔다. 어휘 자료는 난도 높은 전문 용어(법·경제 등 독서 빈출 분야)를 우선한다. 관련: [[suneung-subject-scope]].
