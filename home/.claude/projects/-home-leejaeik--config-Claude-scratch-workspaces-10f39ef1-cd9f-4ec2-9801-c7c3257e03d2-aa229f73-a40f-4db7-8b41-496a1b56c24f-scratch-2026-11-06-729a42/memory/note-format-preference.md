정리노트 PDF는 "베껴쓰기좋게, 디자인은 너무 안예뻐도돼"라고 했다. 색·장식보다 흑백·테두리·표 위주의 필사하기 쉬운 형식으로 만든다.
국어 안키 덱에서는 "독서 단어가 너무 쉬워. 없애. 법 관련 단어를 대폭 추가해"라고 했다.
2026-11-07: "지금부터 크기는 A4 고정이야 pdf를 다시 생성하지는 마" — 앞으로 만드는 모든 PDF는 **A4 판형**으로 고정한다(한때 A5로 만들었던 것은 무효). 이미 만든 PDF는 요청 없이 다시 생성하지 않는다.
사용자에게 하는 모든 말은 **한국어로만** 쓴다. 도구 호출 사이의 짧은 진행 메모까지 포함한다. 2026-11-07, 11-08 두 번이나 진행 메모를 영어로 써서 지적받았다("영어로 말하지마 절대"). 코드·명령어·파일명·에러 원문만 원래 언어로 둔다.
아이폰(AnkiMobile·PDF)에서 본다 → 옛한글은 SVG 도형으로, PDF 한글 글꼴은 TrueType(나눔고딕)으로 넣어야 깨지지 않는다.

**Why:** 손으로 베껴 쓰며 외우는 용도라 장식은 방해가 되고, 기본 한자어는 이미 알고 있어 학습 가치가 낮다. 인쇄 용지는 A4로 정했다.

**How to apply:** 학습 PDF는 A4·흑백 위주에 필사 체크칸을 둔다. 어휘 자료는 난도 높은 전문 용어(법·경제 등 독서 빈출 분야)를 우선한다. 기존 PDF는 사용자가 요청할 때만 다시 만든다. 관련: [[suneung-subject-scope]].
