hermes update 뒤 TUI 시작 정보 칸이 다시 오른쪽 위젯 밑으로 삐져나오면:
  cd ~/.hermes/hermes-agent
  git apply --check ~/.local/share/backups/tui-bodycols-20261119/bodycols.patch && git apply ~/.local/share/backups/tui-bodycols-20261119/bodycols.patch
  (안 맞으면 ui-tui/src/components/appLayout.tsx 에서 <Banner>·<SessionPanel> 의 maxWidth 를 composer.cols - 2 → bodyCols - 2 로 손으로 바꾸기)
  cd ui-tui && PATH=~/.hermes/tools/node-26.12.1-linux-x64/bin:$PATH npm run build
원상복구: git checkout ui-tui/src/components/appLayout.tsx 후 같은 빌드 (또는 entry.js.orig 복사)
